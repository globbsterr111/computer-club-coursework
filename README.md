# Информационная система компьютерного клуба

Приложение на C# и Avalonia для просмотра компьютеров и тарифов, ведения игровых сеансов и регистрации оплат. Данные хранятся в Microsoft SQL Server.

## Быстрый запуск Windows

Скачайте ZIP репозитория, распакуйте его и дважды щёлкните **Запустить_клуб.cmd**. На компьютере нужны .NET 10 SDK и доступный SQL Server. При первом запуске нужно подключение к интернету для скачивания зависимостей.

Скрипт собирает приложение, создаёт учебную базу `computer_club_db` при необходимости и открывает окно каталога. Для создания базы нужны права на её создание в SQL Server. Если база уже подготовлена, скрипт использует её данные. Для нестандартного имени сервера создайте `connection.txt` по приложенному примеру.

## Ручной запуск

1. Установите .NET 10 SDK и запустите SQL Server.
2. Создайте пустую базу `computer_club_db`. В ней последовательно выполните `SQL/01_БД.sql` и `SQL/02_Сеансы.sql`.
3. Скопируйте `connection.example.txt` в `connection.txt`. В копии укажите имя своего экземпляра SQL Server.
4. Откройте `Club.slnx` в Visual Studio или выполните `dotnet run --project Club.csproj` из корня репозитория.

Гостю доступны каталог компьютеров и тарифы. Для первого входа администратора задайте собственный пароль длиной от 12 символов в переменной среды `CLUB_ADMIN_PASSWORD` и один раз запустите `dotnet run --project Club.csproj -- --create-admin admin`. Затем удалите переменную, запустите приложение обычным способом и войдите под логином `admin`.

## Проверки

Проверка хеширования паролей запускается командой `dotnet run --project Tests/Tests.csproj`. Для проверок SQL создайте отдельную базу с именем, начинающимся на `ClubStage7Test_`, и выполните в ней скрипты 01, 02 и 03 по порядку.
